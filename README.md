# Gestor-de-tareas---Fundamentos-de-programaci-n
Realización de un gestor de tareas de manera colaborativa dentro de GitHub. 

## Descripción

Este proyecto consiste en el desarrollo de un gestor de tareas realizado en Python como parte de la asignatura de Fundamentos de Programación.
El programa permite al usuario registrar tareas, visualizar las tareas almacenadas y consultar el porcentaje de progreso de las actividades completadas.
El proyecto fue desarrollado de manera colaborativa utilizando Git y GitHub, con el objetivo de aplicar los conocimientos básicos de programación y control de versiones.
